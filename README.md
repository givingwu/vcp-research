# VCP vs Momentum：可复现的交易策略实验（研究版）

**目的**：检验 VCP 形态、突破与回踩是否对趋势策略提供了额外的样本外价值。**不是 J Law 策略的官方复现，也不构成投资建议。**

## 研究对照

- **A_trend**：趋势过滤（收盘价 > SMA50 > SMA200，SMA50/SMA200 20 日上升）+ 126 日动量在同一供给股票池的前 30% + 收盘创新的 20 日高点。
- **B_vcp_early**：相同趋势、动量过滤 + 过去约 95 根日 K 线内三个递减回撤、缩量、已确认的局部高低点，在突破之前尝试提前介入。
- **C_breakout**：B 的形态 + 收盘突破客观 Pivot + 成交量超过过去 50 日均量的 1.3 倍。
- **D_pullback**：C 发生后约 12 个交易日内，收盘回到 Pivot ±2.5% 内且成交量低于突破日的 80% 时介入。

**重要**：此 VCP 是可计算的近似定义，非 J Law 的精确量化源代码。与视频中的主观形态判断结果可能不同。`B` 的预突破介入是专门为了隔离「形态本身」，不是视频唯一推荐的买点。

每一组共享：单笔账户预定风险 0.35%，单标的最大资金 20%，持仓总名义金额不超过 100%，单向做多，最多 10 只股票；初始 stop 对 A 是入场信号日收盘价的 93%，对 B/C/D 是最近回撤低点下方 0.5%；趋势或前 20 日最低价被跌破则下一个开盘退出，最长持仓 80 根交易日 K 线。默认单边佣金 2bps、滑点 5bps。

> 期望收益不能直接从视频数字推断。日线回测无法精确还原盘中订单队列；保守处理入场日触及 stop 的情形。止损跳空按开盘价执行。此原型不处理停牌时的真实流动性、停牌退市强制处置、保证金、借券、税费、分红和个股公司行为的全面复原。

## 数据与证据层级

**A级（研究最终要求）**：历史成分股、退市股票、拆分/分红处理、按当时可得时间重建的价格/财报/公司行动；多市场时期及独立样本外评估。

**B级（探索性）**：Stooq 下载的当前股票名单，只能做初步探索。存在严重的 **幸存者偏差、供应商复权差异、样本选择问题**，绝不能据此认定真实收益。

**C级（本仓库内模拟数据）**：随机生成的合成行情，仅供单元测试与全链路 smoke test，不能推断策略优劣。该仓库没有离线可验证的大规模真实市场日线数据；本次不编造真实回测收益。

## 正式检验协议

1. **先固定规则、成本模型、股票池以及试验参数**，不允许看了 test 数据后修改规则。
2. 训练期截止 2019-12-31；验证期 2020-01-01 至 2022-12-31；样本外测试期 2023-01-01 至 2026-11-01（只跑已覆盖的实际交易日）。如取得可靠数据，应使用滚动训练/验证，防止单一区间偏差。
3. 对 A/B/C/D 采用完全相同的股票池、限制、滑点与风险预算；输出总回报、CAGR、最大回撤、零无风险利率 Sharpe、已平仓交易数、胜率与平均平仓盈亏。
4. 相比 A，重点检查 B/C/D 的**增量**收益、风险调整后表现、交易次数、换手、市场状态稳定性；样本外交易不足（例如 <100 笔）只能说「证据不足」。
5. 加入等权/市值加权指数买入持有基准、风险暴露归因、bootstrap 置信区间、手续费/滑点敏感性、时间窗口敏感性、参数网格及多重检验校正。
6. **实盘前还需**停牌/涨跌停、跳空、盘中触价顺序、成交量占比、真实订单延迟、拆分/退市等模拟与 walk-forward 阶段测试。

## 风险与实现边界

- 形态转折点只允许在右侧 3 根 K 线确认之后使用，防未来函数；选股只使用同一日及之前的可得信息。策略在当日收盘发出订单，下一日开盘成交。
- `vcp_at` 是无模型训练的规则策略，严格 VCP 出现频率可能很低；交易数过少不允许宣称策略有效。
- `B` 有形态预突破介入，可能更容易被震荡止损。
- `A` 使用 20 日高点突破而不只是趋势确认，让基线成为可交易的趋势突破策略。这是明确的研究设计，并不代表普遍意义上的「动量因子收益」。
- 当前系统按照股票代码字母序分配同时出现的订单资金，可能影响资金竞争，需要稳健性测试。
- 按当前股票列表下载真实行情缺少历史上退市的成分股，结果只供探索，不适合形成交易决策。
- **本项目只提供起点，不构成完成的严谨实证研究。**
